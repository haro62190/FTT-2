# Polices des images du bot

Utilisées pour la carte de rang, la bannière de niveau et le tableau de bord. Toutes sont sous **SIL Open Font License 1.1** (libres, redistribution autorisée), via Google Fonts :

- **Kaushan Script** (Impallari Type) : écriture pinceau
- **Cinzel** SemiBold / ExtraBold (Natanael Gama) : titres gravés, statistiques
- **Yuji Syuku** (Kinuta Font Factory) : kanji pinceau, réduite aux caractères 剣聖浪人両任務
